# pygame_shooting_range

This code is for a Star Wars themed spaceship shooter. You need to shoot down the TIE-Fighters. Every few rounds apears a Star Destroyer and if you play long enough you could encounter the Death Star. You have 3 Lives and if you die your highscore is saved in a .txt file. You can exit the game by pressing the "escape"-key. You need to have a working pygame install for this code to work and you need to download the "Assets"-folder and put it in the same directory the code is in.
